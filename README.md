# Nexora Skill

This repository contains agent skills for working with Nexora. Skills explain safe workflows, domain boundaries, MCP capabilities, and evidence requirements. They do not grant authorization and must never contain credentials.

## Contents

- `skills/nexora-development-workflow/` development workflow guidance.
- `skills/nexora-team-governance/` governance and MCP guidance.

Install or link the skills using the host agent's supported skill mechanism. Review the target environment before installation.
