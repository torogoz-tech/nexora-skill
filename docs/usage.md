# Using a Nexora skill

Read the selected `SKILL.md` completely before acting. The skill is a workflow contract, not a permission grant.

## Before action

Identify the repository, project, tenant, actor, and requested outcome. Separate facts observed from assumptions. Check whether the requested change is reversible and whether an approval or human handoff is required.

## During action

Use only the tools and paths allowed by the active workflow. Preserve relevant evidence: file paths, snapshot IDs, policy versions, test results, API responses, and error messages. Keep source changes and external mutations distinct.

## After action

Report what changed, what was verified, what remains uncertain, and what the human must decide. A skill must never describe an unverified deployment, approval, or publication as complete.

Nexora users can receive these explanations in English or Spanish. Technical identifiers remain unchanged so the same evidence can be followed in either language.
